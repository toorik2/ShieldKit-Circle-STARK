# Goal — Sealed Creation Log Circle STARK V17

## Named research end

Build the smallest intelligible BCH-native system in which one private note
transition is proven by one sealed argument and settled by miners in one
May-2026 consensus transaction.

The relation permits only deposit, full withdrawal, and withdrawal with one
private change note. It has no transfer, merge, split, batching,
administrator, escape route, protocol fee, or trusted host-verification seam.

Only the human user declares this named end complete.

## Design objective

The design law remains:

```text
private relation
    -> one independent full-dimensional seal per protected column
    -> one transcript and one whole quotient
    -> one independently masked degree-corrected FRI batch
    -> one canonical proof
    -> byte-only, value-neutral auxiliary verifier/ROM infrastructure
    -> one state- and value-changing settlement role
```

An optimization belongs only when it deletes, unifies, or makes canonical an
existing mechanism. V17's next phase is preservation, independent assurance,
and simplification. A sub-100,000-byte standard successor is a separate design
problem and may not weaken this relation or privacy membrane.
