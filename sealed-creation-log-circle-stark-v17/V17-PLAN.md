# V17 implementation contract

V17 is a purification successor to frozen v16, not a compatibility layer. The
public relation and privacy membrane stay fixed. Three changes earn the new
version by deleting duplicated machinery or making one existing mechanism
canonical.

## 1. One construction graph

One typed build-time graph owns proof frames, transcript rounds, C1-C33,
commitment geometry, verifier roles, code-ROM candidates, carrier allocation,
identity, and qualification gates. Generated TypeScript, Rust, VM, and human
tables must agree byte for byte. Hand-maintained parallel role and offset lists
are forbidden in the final product graph.

AIR residuals flow directly into composition, quotient, and oracle batching.
The serialized `compositionPartials` bridge is removed. Only regular query
families may use typed dynamic workers; there is no proof-controlled VM
interpreter. Identity-independent repeated function bodies may be placed in
authenticated code-ROM pages only when exact complete-transaction accounting
shows a saving for all three profiles.

## 2. One FRI arithmetic kernel

All query denominators use one prefix/suffix batch inversion with exactly one
field inversion and explicit zero rejection. Four-way folds use one fused
limb-level kernel equivalent to the specified Circle-to-line and line folds.
The proof supplies no inverse, cache, opcode, or execution hint.

## 3. One Merkle language

Matrix commitments are binary. FRI layers whose verifier opens complete
quartets use one quartet leaf level followed by binary levels; the final
pair-opening layer is binary. One descriptor, one domain separation, one
canonical traversal, one strict codec, and one generated cut planner own both
shapes. The proof never selects arity, labels, indices, levels, or merge steps.

## Qualification law

The target label is only `offline-theorem-qualified-candidate`. Qualification
fails closed if any required row is `conjectural`, `unresolved`, `skipped`, or
`cache-only`.

For every integer `1 <= T < 2^128`, the exact round-by-round ROM bound must
satisfy `epsilon(T) / T <= 2^-100`. The only quantum statement is: no known
polynomial-time quantum break under the stated assumptions. QROM zero
knowledge remains a nonclaim.

Every canonical schedule, all three relation profiles, and every miner-run
role must fit one May-2026 BCH consensus transaction no larger than 1,000,000
bytes. The 100,000-byte standard relay target belongs to a later version.
Grinding may improve a named proof round; it may never select a convenient
proof layout.

Only the human user declares the named end complete.
